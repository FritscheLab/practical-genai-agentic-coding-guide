# Follow one language from setup to handoff

Choose a path once. Its setup page lists the six lessons—orient, specify, implement, verify, review, and hand off—and each lesson links to the next step in that language.

- **[Python path](../paths/python/index.md):** setup, demo, and six lessons using Python.
- **[R path](../paths/r/index.md):** setup, demo, and six lessons using R.

Both paths repair a plotting function using the same invented category totals, check the image and values, and leave a handoff. The [45-minute workshop](../lab_meeting/45min_runbook.md) provides a guided introduction.

The [shared exercise specification](02-specify.md) records the plotting requirements and fixed values. Use your path's Lesson 2 to work through it and prepare your brief.
