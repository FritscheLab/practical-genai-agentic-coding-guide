# Working in the example repository

Find the plotting code, check the figure and its values, and leave enough evidence for someone else to reproduce it.

Include accessibility in the task and review: readable text, contrast, meaningful labels, and a text alternative.

- [Keep control of the agent](../reference/agent-control.md): permissions, sandboxing, and independent coding skills.
- [Work with tools](tool_selection.md) for inspection, edits, and checks.
- [Navigate the repository](repo_navigation.md) using entrypoints and focused searches.
- [Test the method](testing.md) with independent expectations and integration checks.
- [Record plot runs](logging_and_runs.md) with commands, image paths, and check results.
- [Describe plotting values](data_dictionaries.md) alongside the contract.

Put reusable rules in `AGENTS.md` and decisions for one change in its task brief. For reusable skills and the `SKILL.md` format, see [portable context](../platforms/portable-context.md).
