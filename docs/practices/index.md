# Working in this repository

These pages explain the habits we use when working together on this repository: finding the relevant code, checking a calculation, and leaving enough information for someone else to repeat a run.

- [Work with tools](tool_selection.md) for inspection, edits, and checks.
- [Navigate the repository](repo_navigation.md) using entrypoints and focused searches.
- [Test the method](testing.md) with independent expectations and integration checks.
- [Record runs](logging_and_runs.md) with parameters, provenance, and diagnostic outputs.
- [Maintain data dictionaries](data_dictionaries.md) alongside the contract.

As you work, put rules that apply across tasks in `AGENTS.md` and decisions for the current change in its task brief. Keep longer explanations here, where both people and agents can find them when needed. For reusable agent skills and the `SKILL.md` format, see [portable context](../platforms/portable-context.md).
