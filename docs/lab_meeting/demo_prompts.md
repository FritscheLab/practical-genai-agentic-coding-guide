# Prompts for the workshop

Send participants to their language path at the start. Each lesson already supplies a copyable prompt with that language and its files filled in. Participants can keep using Next to follow the exercise.

| Stage | Python prompt | R prompt |
| --- | --- | --- |
| Orient | [Python Lesson 1](../paths/python/01-orient.md) | [R Lesson 1](../paths/r/01-orient.md) |
| Describe the change | [Python Lesson 2](../paths/python/02-specify.md) | [R Lesson 2](../paths/r/02-specify.md) |
| Implement | [Python Lesson 3](../paths/python/03-implement.md) | [R Lesson 3](../paths/r/03-implement.md) |
| Review | [Python Lesson 5](../paths/python/05-review.md) | [R Lesson 5](../paths/r/05-review.md) |
| Hand off | [Python Lesson 6](../paths/python/06-handoff.md) | [R Lesson 6](../paths/r/06-handoff.md) |

Use planning while the group still has questions about the approach. Discuss the six-row example and the report, then switch to implementation. Keep the [shared example](../lessons/02-specify.md) available to the facilitator.

A handoff request can be shared across languages:

```markdown
Leave a short handoff: what changed, the commands and results we checked,
and anything unfinished. Include how to rerun the example.
```
