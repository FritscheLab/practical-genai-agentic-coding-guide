# Work through a change together

The [45-minute runbook](45min_runbook.md) is a session you can lead with your group. The [six lessons](../lessons/index.md) are there to work through at your own pace. Install dependencies and run the baseline before the session; use the meeting for reasoning and review.

- [Runbook](45min_runbook.md): agenda, preparation, and checkpoints.
- [Demo prompts](demo_prompts.md): concise requests for orientation, implementation, and review.
- [Instructor solution](instructor-solution.md): reference implementation and independent verification.

Slides are maintained as [Quarto source](https://github.com/FritscheLab/practical-genai-agentic-coding-guide/blob/main/docs/lab_meeting/slide_deck.qmd). Run `quarto render docs/lab_meeting/slide_deck.qmd` from the repository root. Rendered HTML is a local slide deck and stays ignored.

Give participants time to explain the counting rule, inspect a changed file, and read a run summary themselves. By the end, they should have a brief, a tested change, and a handoff they can use to continue after the meeting.
