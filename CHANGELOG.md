# Release notes

## 0.1.0 — initial publication candidate

Part 2 of the Fritsche Lab Practical GenAI series introduces a complete maintenance exercise on a synthetic research repository.

- Six lessons covering orientation, specification, implementation, verification, review, and handoff.
- Lab-aligned documentation site with series navigation, search, and responsive layouts.
- Dated setup guides for Codex, Claude Code, GitHub Copilot, Cursor, and Gemini CLI, plus a primary-source review of current practices.
- Practical guidance on asking, planning, implementation, tool results, permissions, and longer tasks.
- Shared `.codex` configuration and reviewer, a discoverable `.agents/skills` review procedure, and setup maps across clients.
- A model/client setup comparison in Lesson 1, with U-M data policies, PHI/PII boundaries, and practical sharing guidance throughout the workflow.
- A quality-gate exercise with independent acceptance checks and an isolated, executable instructor solution.
- A validated baseline pipeline with deterministic selection, explicit data contracts, failure evidence, and input/output provenance.
- Reproducible synthetic fixtures, a focused review skill, task and handoff templates, and automated publication checks.

This is a teaching release. The pipeline uses simplified rules and does not implement a validated clinical analysis or Part 1's advanced adult-cohort plan. Hosted-client operation requires a separately configured environment and approved account. Publication and release dates should be recorded when a tagged release is actually made.
